📘 HSK 1 · Грамматика

Новая версия экзамена · Полный список
1. 语素 (Морфемы)
1.1 前缀 (Префиксы)
  • 小— 小 + существительное (уменьшительно-ласкательное) 小张、小狗
  • 第— 第 + числительное (порядковые числительные) 第一、第二
1.2 后缀 (Суффиксы)
  • —们 множественное число для личных местоимений и одушевлённых существительных 我们、同学们
  • —边 указывает на сторону/направление 这边、那边、左边、右边
2. 词类 (Части речи)
2.1 名词 (Существительные)
  • 方位名词 上、下、里、外、前、后 桌子上、教室里
2.2 动词 (Глаголы)
  • 能愿动词 (Модальные) 会、能、想、要、可以 我会说汉语、我想喝水
  • 离合词 (Разделяемые) 看病、睡觉、说话、上课、下课、上班、下班、生病 我看病、睡觉了
2.3 代词 (Местоимения)
  • 疑问代词 多、多少、几、哪、哪儿、哪里、哪些、什么、谁、怎么、怎么样 多少钱？你是谁？
  • 人称代词 我、你、您、他、她、我们、你们、他们、她们、它、它们、大家 我是学生
  • 指示代词 这、那、这儿、那儿、这里、那里、这些、那些、有的、这个、那个、有些 这是书、那个是电脑
2.4 数词 (Числительные)
  • 一、二/两、三、四、五、六、七、八、九、零、十、百、半、千 一百、两千、半小时
2.5 量词 (Счётные слова)
  • 名量词 (Счётные) 本、个、家、口、块、件、只、元 一本书、三个人
  • 借用名量词 杯 一杯水
  • 时量词 (Времени) 日、号、岁、点、分、年、天 今天、十岁、三点
2.6 副词 (Наречия)
  • 程度副词 非常、很、太、真、有（一）点儿 很好、太热了
  • 范围副词 都 我们都来了
  • 时间副词 在、正在 他在看书、正在吃饭
  • 频率副词 再 再见、再来
  • 关联副词 还、也 我还有事、我也去
  • 否定副词 不、没（有）、不要 不是、没有钱、不要
2.7 介词 (Предлоги)
  • 引出时间、处所 在 在北京、在三点
  • 引出对象 和、对 和你说、对他笑
2.8 连词 (Союзы)
  • 连接词语或短语 和 我和你、爸爸和妈妈
2.9 助词 (Частицы)
  • 结构助词 的 我的书、红色的
  • 动态助词 了 我吃了饭
  • 语气助词 吧、了、吗、呢 走吧、好了、好吗？你呢？
2.10 叹词 (Междометия)
  • 喂 喂，你好！
3. 短语 (Словосочетания)
3.1 结构类型
  • 联合短语 老师和同学、又大又红
  • 偏正短语 很大的房子、慢慢走
  • 动宾短语 看书、喝茶、去学校
  • 主谓短语 天气好、我喜欢
  • 数量短语 三个、两本书
  • 介宾短语 在北京、从学校
  • 方位短语 桌子上、教室里
4. 句子成分 (Члены предложения)
  • 主语 名词、代词或名词性短语 我、他、学校
  • 谓语 名词、代词、数词、数量短语、动词、形容词 他是老师、天气好
  • 宾语 名词、代词或名词性短语 看书、喝茶
  • 定语 名词性词语、形容词性短语、数量短语 我的书、大房子
  • 状语 副词、形容词、表示时间处所的词语 很好、慢慢走、今天去
  • 补语 动词 + 动量补语 去一次、看一遍
5. 句子的类型 (Типы предложений)
5.1 句型
  • 主谓句1 动词谓语句 我吃饭、他去学校
  • 主谓句2 形容词谓语句 天气很好、他很高兴
  • 主谓句3 名词谓语句 今天星期六、他中国人
  • 非主谓句 下雨了、请进！
5.2 句类
  • 陈述句 我是学生、今天很冷
  • 疑问句 是非问、特指问、正反问 你好吗？你去哪儿？你是不是学生？
  • 祈使句 请坐！别说话！
  • 感叹句 太好了！真漂亮！
5.3 特殊句型
  • “是”字句1 表示等同或类属 他是老师、这是书
  • “有”字句1 表示领有 我有一本书、他有三个朋友
  • 存现句1 处所 + 是/有 + 名词 桌子上有一本书、学校后边是商店
  • 连动句1 前后动作先后发生 我去商店买东西、坐车去学校
  • 双宾语句1 主语 + 动词 + 宾语1 + 宾语2 我给他一本书、他问我一个问题
5.4 复句
  • 并列复句 ……，也……；……，还…… 他喜欢音乐，也喜欢运动
6. 动作的态 (Виды действия)
  • 完成态 用动态助词“了”表示 我吃了饭、他来了
  • 变化态 用语气助词“了”表示 下雨了、他走了
  • 进行态 在/正在 + 动词；在/正在 + 动词……呢；……呢 他在看书、他正在吃饭呢
7. 特殊表达法 (Особые выражения)
  • 钱数表示法 十块五毛、一百二十元
  • 序数表达法1 第 + 数词 第一、第二十
  • 时间表示法 年、月、日、星期；钟点 2026年9月8日、星期天、三点二十分

1. 语素 (Морфемы)
  • 后缀 —面 前面、后面、上面、下面
2. 词类 (Части речи)
2.1 名词
  • 方位名词 左、右 左边、右边
2.2 动词
  • 动词重叠 AA、A一A、A了A、ABAB 看看、看一看、看了看、讨论讨论
  • 能愿动词 可能 他可能来了
  • 离合词 帮忙、游泳、跳舞、跑步 帮个忙、游了泳
2.3 代词
  • 疑问代词 为什么 你为什么不来？
  • 人称代词 自己 我自己去
  • 指示代词 那么、那样、这么、这样、每 那么远、这样好、每个人
2.4 形容词
  • 形容词重叠 AA、AABB 红红的、高高兴兴
2.5 数词
  • 万、好多、多 一万、好多人、多大
2.6 量词
  • 名量词 条、位、间、名 一条鱼、一位老师
  • 借用名量词 包 一包糖
  • 动量词 次 去一次、看三次
2.7 副词
  • 程度副词 多、好、最 多大、好冷、最好
  • 范围副词 一起 一起去
  • 时间副词 还、已经、有时、快、快要、正 还没来、已经走了
  • 频率副词 常、经常 他常来、经常去
  • 否定副词 别 别说话！
  • 关联副词 再、就 再来、就去
  • 语气副词 都、就、还是 都九点了、还是你
2.8 介词
  • 引出时间、处所 从 从北京来、从明天开始
  • 引出方向、路径 往、从 往前走、从右边走
  • 引出对象 给、比、跟 给我书、比他高、跟我去
  • 引出原因 因为 因为下雨，我不去了
2.9 连词
  • 连接词或短语 跟 我跟他一起去
  • 连接分句 但、但是、那、虽然、还是、因为、所以 虽然很累，但是很高兴
2.10 助词
  • 结构助词 得、地 跑得快、高兴地说
  • 动态助词 过、着 去过北京、坐着看书
  • 语气助词 呢、吧、的、啊 在哪儿呢？走吧、是的
3. 短语 (Словосочетания)
  • 动补短语 说完、做好
  • “的”字短语 我的、红的、大的
  • 连谓短语 去商店买东西
  • 兼语短语 请他来、让他去
  • 固定短语 什么的 买点水果什么的
4. 固定格式
  • 还是……吧 还是你去吧
  • 要/快要/就要……了 要下雨了、快要考试了
  • 都……了 都十二点了
5. 句子成分
  • 受事主语 作业写完了、饭做好了
  • 名词性短语作谓语 他很高、今天星期三
  • 动词/主谓短语作定语 去的朋友、他买的书
  • 结果补语 动词 + 错/懂/好/会/完 写错了、看懂了
  • 趋向补语 动词 + 来/去；上/下/进/出/过/回 拿来、出去、回来
  • 复合趋向补语 出来、出去、过来、过去、回来、回去、进来、进去、起来、上来、上去、下来、下去
  • 状态补语 动词 + 得 + 形容词性短语 跑得很快、高兴得跳起来
  • 数量补语 表示动作持续的时间 等了三个小时、比他高五厘米
6. 句子的类型
  • 主谓谓语句 他身体很好、北京天气很好
  • 选择问句 用“还是”连接 你喝茶还是咖啡？
  • 祈使句 用“别” 别说话！别走！
  • “是”字句2 表示说明或特征 他是中国人、这是红色的
  • “有”字句2 表示达到 有十个人、有三百页
  • 存现句2 处所 + 动词 + 着 (+数量短语) + 名词 桌子上放着一本书
  • 比较句1 A比B+形容词；A有/没有B+形容词 他比我高、他没有我高
  • “是……的”句1 强调时间、地点、方式 我是昨天来的、他是坐车去的
  • 兼语句1 表使令：主语 + 请/叫/让……+宾语1+动词+宾语2 老师让我回答问题
  • 双宾语句2 主语 + 动词 + 给 + 宾语1 + 宾语2 我给他一本书
复句
  • 选择复句 （是）……，还是…… 你是去还是不去？
  • 转折复句 虽然……，但是…… 虽然很累，但是很高兴
  • 因果复句 因为……，所以…… 因为下雨，所以我不去了
  • 紧缩复句 一……就…… 我一到就给你打电话
7. 动作的态
  • 持续态 动词 + 着：表示状态的持续或动作的持续 门开着、他坐着看书
  • 经历态 用动态助词“过”表示 去过北京、吃过饭了
8. 特殊表达法
  • 序数表示法2 数词 + 量词 三号、五楼
  • 概数表达法1 用“几”表示概数；数词 + 多 + 量词；数词 + 量词 + 多 几个人、十多岁、三年多

📙 HSK 3 · Грамматика

Новая версия экзамена · Полный список
1. 语素 (Морфемы)
  • 前缀 老— 老师、老板、老公
  • 后缀 —家、—子、—员 画家、桌子、演员
2. 词类 (Части речи)
2.1 名词
  • 方位名词 东、南、西、北、北方、东方、南方、西方、中间 北京在北方、坐在中间
2.2 动词
  • 能愿动词 需要、该、应该、愿意、得 需要帮助、应该去
  • 离合词 动宾式：放假、见面、结婚、洗澡；动补式：离开、完成、分开 放三天假、见一次面
2.3 代词
  • 疑问代词 怎样 你怎样去？
  • 疑问代词非疑问用法 任指：疑问代词 + 都……；疑问代词 + 疑问代词 谁都知道、去哪儿都行
  • 人称代词 别人、咱们 别人都说好、咱们走吧
  • 指示代词 别的、其他 别的书、其他人
2.4 量词
  • 名量词 把、双、张、种、层、封、页、辆、节、所、班、段、头、句、公斤、斤、角、毛、刻、米 一把刀、一双鞋
  • 借用名量词 碗、盘 一碗饭、一盘菜
  • 动量词 口、回、遍、声 吃一口、去一回
  • 量词重叠 个个、张张 个个都来了、张张桌子
2.5 副词
  • 程度副词 比较、还、更、特别、挺、有些、越、极 比较好、更大了
  • 范围副词 就、一块儿、一共、只、到处、只是 就我一个人、一共五个人
  • 时间副词 才、马上、先、一会儿、刚、刚刚、一直 才来、马上到
  • 频率副词 总、总是、又、常常 总是迟到、又来了
  • 关联副词 一边 一边走一边看
  • 情态副词 大概、必须、差不多、一定、好像、几乎 大概来了、差不多好了
  • 语气副词 当然、其实、终于、才 当然可以、终于到了
  • 否定副词 不必、不用 不必担心、不用谢
2.6 介词
  • 引出对象 为、向、关于 为你高兴、向老师学习
  • 引出方向、路径 向 向前走
  • 引出目的、原因 为了、为 为了健康、为人民服务
  • 引出施事、受事 把、被 把门关上、被他看见了
  • 引出凭借、依据 根据 根据天气预报
2.7 连词
  • 连接词或短语 或、或者 今天或明天、茶或者咖啡
  • 连接分句 只有、只要、不但、而且、如果、可、可是、然后 不但聪明而且努力
2.8 助词
  • 其他助词 的话 明天的话、不去的话
3. 短语 (Словосочетания)
  • 同位短语 我的朋友小王、首都北京
  • 动补短语2 说完、做好、洗干净
  • 数量重叠 数词 + 量词 + 数词 + 量词 一个一个、一天一天
  • 四字格 不A不B 不大不小、不多不少
  • 固定短语 不一会儿、看来、在……看来、越来越、看起来、看上去、一般来说、不怎么样
4. 固定格式
  • 除了……（以外），……还/也/都…… 除了他，我们都来了
  • 从……起 从现在起
  • 对……来说 对我来说
  • 一……也/都+不/没…… 一个字也不认识
  • 一点儿也不 一点儿也不累
  • 越……越…… 越来越好、越多越好
  • （在）……以前/以后/前/后 吃饭以前、下课以后
  • X什么（啊） 看什么看、忙什么啊
  • 该……了 该吃饭了、该走了
  • 在……上/下/中 在桌子上、在老师的帮助下
5. 句子成分
  • 动词/形容词作主语 学习很重要、开心就好
  • 主谓短语作主语 他来不来还不知道
  • 多项定语 我的一本新书、那个漂亮的女孩
  • 结果补语2 动词 + 到/住/走/上 看到、抓住、带走、考上
  • 趋向补语2 引申用法：表示结果意义：动词+出/起/下；表示开始：动词+上/起来；表示持续：动词+下去/下来 看出、想起来、坚持下去
  • 可能补语 动词 + 得/不 + 动词/形容词 吃得完、吃不完、看得清楚
  • 程度补语 形容词 + 得很；形容词/动词 + 极了/坏了 好得很、高兴极了
  • 数量补语3 表示动作结束到某个时间点的间隔时间 来了三天了、走了两个小时了
6. 句子的类型
6.1 句类
  • 疑问句 “怎样+动词”的特指问 怎样学习？
  • 反问句 不是……吗？ 你不是知道吗？
6.2 特殊句型
  • “把”字句 主语+把+宾语+动词+在/到+处所；主语+把+宾语+动词+结果/趋向/状态补语 把书放在桌子上、把房间打扫干净
  • 被动句 主语+被+宾语+动词+其他成分；主语+被+动词+其他成分 书被他拿走了、饭被吃完了
  • 连动句2 “着”表示动作的伴随：动词1+着+动词2 坐着看书、站着说话
  • 比较句2 A比B+更/还+形容词；A跟B一样；A不比B+形容词 他比我更高、我跟他一样高
  • 存现句3 表示出现/消失：处所词+动词+趋向补语+了+数量短语+人/物 门口来了一个人、桌子上少了一本书
  • “是……的”句2 强调说话人的看法或态度 我是不会去的
  • 重动句 主语+动词+宾语+动词+补语 他看书看得很快
6.3 复句
  • 承接复句 先……，再/然后…… 先吃饭，再去看电影
  • 选择复句 或者……，或者…… 或者你来，或者我去
  • 并列复句 一会儿……，一会儿……；又……，又……；一边……，一边…… 又高又大
  • 递进复句 不但……，而且…… 不但聪明，而且努力
  • 转折复句 虽然……，可是…… 虽然很累，可是很高兴
  • 假设复句 如果……，就……；……的话，就…… 如果下雨，我就不去了
  • 条件复句 只有……，才……；只要……，就…… 只有努力，才能成功
  • 目的复句 为了……，…… 为了健康，我每天跑步
  • 紧缩复句 ……了……（就）…… 吃了饭就走
7. 特殊表达法
  • 概数表达法2 用“大概”表示概数；相邻数词连用表示概数 大概三十个人、五六个人
